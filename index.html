Renders each ad in a sandboxed iframe, scrubs its CSS animations frame-by-frame via the Web Animations API, then quantizes and encodes a GIF locally. No server, no tracking.
Tip: Dither off (default) keeps flat-color ads tiny. Turn it on only for gradient-heavy creative.
